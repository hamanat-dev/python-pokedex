# 📖 Python Pokédex
A beginner-friendly command-line Pokédex built with Python that retrieves Pokémon information from the PokéAPI.
This project was created to practice working with REST APIs, JSON data, functions, dictionaries, and user input while building a useful terminal application.

## Features
	-	🔍 Search for any Pokémon by name
	-	⚔️ Compare two Pokémon
	-	📊 Display base stats
	-	✨ View Pokémon types and abilities
	-	🌐 Retrieve live data from the PokéAPI
	-	❌ Handle invalid Pokémon names gracefully

## Technologies Used
	-	Python 3
	-	Requests
	-	PokéAPI

## Installation
Clone the repository:
git clone https://github.com/your-username/python-pokedex.git
Navigate to the project folder:
cd python-pokedex
Install the required package:
pip install requests
Run the application:
python pokedex.py
